Namespace Cad2Gdml.Meshes (check the namespace used in Mesh.cs and use the same). Create `public static class ComponentSplitter` with ONE public method:
`public static List<List<int>> Components(Mesh welded)` returning lists of TRIANGLE indices (ti means triangle ti = Indices[ti*3..ti*3+2]); every triangle appears in exactly one list; C# 7.3, net48, no external packages.
Rule: two triangles belong to the same component only if they share an edge (an unordered vertex pair) that is used by EXACTLY two triangles in the whole mesh (a manifold edge). Edges used by 3 or more triangles join nothing, and a shared single vertex joins nothing (so bodies touching along an edge or at a point stay separate components). Open (boundary) edges join nothing.
Implementation: union-find over triangle indices with path compression (iterative Find, no recursion); edge key = (long)lo * vertexCount + hi, with vertexCount = welded.Vertices.Count; use Dictionary<long,int> for the first triangle of an edge and Dictionary<long,int> for the count and Dictionary<long,int> for the second triangle; union only edges with count == 2. O(T) time. Degenerate triangles (two equal indices) are skipped for edge purposes but still returned in a component of their own.
Output order must be deterministic: components ordered by the smallest triangle index they contain; triangles inside a component ascending. Empty mesh -> empty list. Keep it compact; think briefly.
