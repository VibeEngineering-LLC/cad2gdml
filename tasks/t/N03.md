Namespace Cad2Gdml.App (WinForms, net48, C# 7.3, System.Drawing only). Create `public sealed class MeshView : Control` — a software 3D viewer of a scene with mouse rotation, wheel zoom, a cutting plane and highlight of one part. Use `DoubleBuffered = true`, ResizeRedraw, BackColor White, SetStyle(AllPaintingInWmPaint | UserPaint).
Public API: `void SetScene(SceneModel scene)` (copies a reference list of Parts that have Mesh != null; computes the scene bounding box centre and radius (half of the box diagonal); resets yaw = 30, pitch = 20 (degrees), zoom 1, section off; precomputes for every part a triangle budget: at most 40000 triangles over the whole scene, distributed proportionally to each part's triangle count with a minimum of 12 per part, taking every k-th triangle (k = ceil(count/budget)) — deterministic); `string Highlight { get; set; }` (part name or null, Invalidate on change); `bool SectionEnabled { get; set; }`, `int SectionAxis { get; set; }` (0 = x, 1 = y, 2 = z), `double SectionPos { get; set; }` (0..1 across the scene bounding box along that axis; Invalidate on change); `void ResetView()`; `event EventHandler ViewChanged` (raised after any interaction).
Behaviour: left mouse drag changes yaw (dx * 0.5 deg) and pitch (dy * 0.5 deg, clamped to -89..89); mouse wheel multiplies zoom by 1.1 / 1/1.1 (clamped 0.1..20); right mouse drag pans (screen offset). Projection: orthographic; rotate scene-centre-relative points by yaw about the vertical (scene y axis is NOT special: use the screen vertical = scene z when pitch is applied, i.e. standard turntable with z up), scale = zoom * 0.45 * min(Width, Height) / radius. Painting: for every kept triangle compute the rotated vertices and the depth (mean of the rotated depth coordinate); skip triangles whose centroid lies on the removed side of the cutting plane when SectionEnabled (keep centroid coordinate <= plane position along the axis, where plane position = bbox min + SectionPos * (bbox max - bbox min)); sort all triangles by depth far-to-near (Array.Sort on a float key array with an int index array) and fill them with `Graphics.FillPolygon` (SmoothingMode None for speed during drag, HighQuality for the final repaint is NOT needed) using the colour of the part: `Palette.ColorHex(part.Role, part.Name)` from Cad2Gdml.Sketch converted to Color (parse "#RRGGBB" or "RRGGBB"; fall back to gray), shaded by a lambert factor 0.55 + 0.45 * |n·light| with a fixed light direction (0.3, 0.5, 0.8) in view space where n is the rotated triangle normal; draw a thin edge pen (colour 40,40,40, alpha 60) only when fewer than 12000 triangles are drawn. When Highlight != null the highlighted part is drawn LAST in orange (255,140,0) with full opacity and every other part with alpha 90 (so the part is visible inside). When SectionEnabled draw a thin dashed rectangle outline of the cutting plane projected from the bbox (4 corners) in colour (200,0,0). Draw a small axes gizmo in the lower-left corner (x red, y green, z blue, 40 px). Everything wrapped in try/catch so Paint never throws (on exception draw the message text). No timers, no threads.
