Namespace Cad2Gdml.Tests. Own mini test runner (no packages): `static class Program { static int Main(string[] args) }` runs registered checks, prints "PASS name" / "FAIL name: reason" in Russian-free ASCII, final line `TESTS passed=N failed=M`, returns 0 only if failed==0. A check is `Action` that throws on failure; helper `Assert(bool, string)` and `AssertNear(double expected, double actual, double tol, string what)`.
Temp dir per run under Path.GetTempPath()/cad2gdml_tests_<guid>, deleted at the end.
Checks (each uses Fixtures and Cad2GdmlPipeline.Run with PipelineOptions inputs):
1. scene_ok: WriteScene, run with UnitToMm=1, ExitCode==0, GDML file exists, contains exactly one `<tessellated` OR tube solids for recognised parts: GdmlWriteResult.Tubes >= 1; crystal part Role==Crystal and Shape.Kind==Tube with RMax within 0.01 of 25.4 and length within 0.01 of 50.8.
2. determinism: run twice into two folders; GdmlWriteResult.Sha256 equal.
3. prism_not_cylinder: crystal replaced by Prism(25.4, 50.8, 6): crystal Shape.Kind must be Tessellated (not Tube).
4. cylinder_24_is_tube: crystal = Cylinder with exactly 24 segments: Kind==Tube.
5. unit_missing: UnitToMm==0 => ExitCode==2 and a diagnostic E_UNIT_MISSING.
6. open_mesh: RemoveOne a triangle from the crystal STL => ExitCode==3.
7. flipped_mesh: FlipAll on the sample => ExitCode==0 and diagnostics contain W_MESH_FLIPPED; volumes positive.
8. inch_unit: same scene scaled by 1/25.4 with UnitToMm=25.4 gives crystal RMax within 0.01 of 25.4.
9. no_crystal: files named a.stl, b.stl only => ExitCode==4.
10. png_written: PngPath exists and length > 1000.
