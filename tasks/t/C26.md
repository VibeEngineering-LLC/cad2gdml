It removes zero-area ("sliver") triangles that arise from T-junctions after welding, WITHOUT opening holes. `Mesh` has `List<Vec3d> Vertices` and `List<int> Indices` (3 per triangle); read Mesh.cs for the exact API and for how to create a Mesh (`new Mesh()`, `Vertices.AddRange`, `Indices.AddRange`).

Algorithm. Work on an `int[]`-triple list `tris` copied from src. Repeat up to 20 passes while something changed: (1) mark a triangle as sliver when two of its indices are equal, or when its area < 1e-9 mm² OR (height over the longest edge)/(longest edge) < 1e-7 (compute with cross product length: area = |cross|/2, height = 2*area/longest). (2) For a sliver with duplicate indices: just delete it (count it). (3) For a collinear sliver with vertices P,Q,R: M = the vertex between the other two (the one whose projection on the longest edge lies strictly inside), A and C = the ends of the longest edge, so the sliver is (A,M,C) in some order. Find, via a dictionary from directed edge (u,v) to triangle index, a triangle T != sliver that contains the edge between A and C in either direction (prefer the one that is not itself a sliver). If found: let T contain directed edge (u,v) where {u,v} = {A,C} and third vertex X; replace T by two triangles (u,M,X) and (M,v,X) (same winding as T); delete the sliver; count it. If no neighbour is found, keep the sliver (skip, do not count). Rebuild the edge dictionary after each pass. Finally build the output Mesh with the same Vertices list (copy) and the remaining triangles; `fixedCount` = number of slivers removed; if 0 return `src` unchanged. Keep it compact; think briefly.
