FIX the existing file (return the COMPLETE corrected file, keep public API: GdmlName.Make, GdmlWriter.Write, GdmlWriteResult). Defects found by an audit against the real GDML format:
(1) STRUCTURE FORMAT. A volume must be written as `<volume name="X"><materialref ref="MAT"/><solidref ref="SOLID"/><auxiliary auxtype="..." auxvalue="..."/></volume>` (materialref and solidref are CHILD elements, not attributes). The world volume contains `<physvol name="PV_X"><volumeref ref="X"/><position name="pos_X" unit="mm" x=".." y=".." z=".."/></physvol>` (volumeref is a child element, never `ref=` on physvol). The material reference must use the canonical material name from the library definition (MaterialDef.Name).
(2) PLACEMENT. Tube and Box solids are centred on their own origin; SolidShape has X0, Y0 and the axial range Z0..Z1 (for Box X0,Y0,Z0 is the centre, Z1==Z0). Emit the physvol position: Tube -> (X0, Y0, (Z0+Z1)/2) and `z` = Z1-Z0 full length; Box -> (X0, Y0, Z0) with full lengths BoxX BoxY BoxZ; Polycone: zplane z values are absolute so position = (X0, Y0, 0); Tessellated: vertices are absolute so no `<position>` (omit it, or write 0 0 0). Positions are written inline in the physvol, not in <define>.
(3) NUMBER FORMAT: one helper `Fmt(double)` = round to 6 decimals, invariant culture, plain notation (no exponent), trailing zeros trimmed, "-0" becomes "0". Angles: `aunit="deg" startphi="0" deltaphi="360"`. Lengths `lunit="mm"`.
(4) ROLES: write TWO auxiliary elements per volume: `<auxiliary auxtype="BecqMoni:Role" auxvalue="crystal|source|vessel|shield|housing|other"/>` (PartRole.Container is "vessel", lower case, others lower case of the enum name) and `<auxiliary auxtype="Cad2Gdml:Role" auxvalue="<enum name>"/>`.
(5) NAMES: GdmlName.Make returns ASCII only: transliterate Cyrillic, replace every char that is not [A-Za-z0-9_] by '_' (including accented letters and Greek), collapse repeats, prefix 'p' if it starts with a digit, avoid the substring "0x" by writing it as "0_x", cut to 64 chars, unique with _2,_3 using the `used` set. Volume name = GdmlName of the part; solid name = name + "_s"; physvol "PV_"+name.
(6) A Tessellated solid must contain at least one triangular facet; if a part has zero triangles throw InvalidDataException("E_MESH_EMPTY: name"). Emit only vertices that are used. Triangles must use `<triangular vertex1="v1" vertex2="v2" vertex3="v3" type="ABSOLUTE"/>`.
(7) MATERIALS: a material name used by a part but not defined in the library -> throw InvalidDataException("E_MAT_UNKNOWN: name"); an element symbol that is not in the built-in element table -> InvalidDataException("E_ELEMENT_UNKNOWN: sym"). `<element name="X" formula="X" Z="n"><atom value="A"/></element>` (atom child element for the atomic mass). Output deterministic: identical input gives identical bytes; UTF-8 without BOM, LF newlines.
