The world volume contains `<physvol name="PV_X"><volumeref ref="X"/><position name="pos_X" unit="mm" x=".." y=".." z=".."/></physvol>` (volumeref is a child element, never `ref=` on physvol). The material reference must use the canonical material name from the library definition (MaterialDef.Name).

Positions are written inline in the physvol, not in <define>.

(4) ROLES: write TWO auxiliary elements per volume: `<auxiliary auxtype="BecqMoni:Role" auxvalue="crystal|source|vessel|shield|housing|other"/>` (PartRole.Container is "vessel", lower case, others lower case of the enum name) and `<auxiliary auxtype="Cad2Gdml:Role" auxvalue="<enum name>"/>`.

(6) A Tessellated solid must contain at least one triangular facet; if a part has zero triangles throw InvalidDataException("E_MESH_EMPTY: name"). Emit only vertices that are used. Triangles must use `<triangular vertex1="v1" vertex2="v2" vertex3="v3" type="ABSOLUTE"/>`.
(7) MATERIALS: a material name used by a part but not defined in the library -> throw InvalidDataException("E_MAT_UNKNOWN: name"); an element symbol that is not in the built-in element table -> InvalidDataException("E_ELEMENT_UNKNOWN: sym"). `<element name="X" formula="X" Z="n"><atom value="A"/></element>` (atom child element for the atomic mass).
