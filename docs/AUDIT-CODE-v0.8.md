## 4. Проверено, дефектов не найдено

- Ориентация крышек для выпуклых дыр: объёмы сохраняются (1000,0000 мм³ на боксах), `neg=0`, `abs=signed` на 32 случайных наборах и 18 диагональных парах (`dg_*`). Знак объёма после заделки корректен.
- Время заделки малых входов: 100 дыр (90 на сфере 4 860 тр.) 0,25 с; 1 млн тр. без дыр 6,3 с.
- GdmlName.Make: `longnames` (5 файлов по 70 одинаковых символов), `dup` (два `part.stl`): имена volume/physvol/solid/material уникальны, длина ≤67 (`S\o\longnames`, `S\o\dup`).
- Детерминизм (в).
- StepImporter: пробелы и кириллица в пути STEP работают; нет взаимной блокировки потоков вывода (5+5 МБ); таймаут и убийство процесса (venv-лаунчер Python 3.12 стартует дочерний процесс, но после `Kill()` дочерних процессов не осталось); временная папка удаляется (в том числе после таймаута и ошибки); код 0 при пустом выводе даёт E_STEP_EMPTY; несуществующий/пустой/битый STEP и отсутствие модуля дают код 2.
