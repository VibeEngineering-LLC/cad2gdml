### V1. Важная. Тела с общей гранью одинакового контура не разделяются: остаётся одно неманифольдное «тело» с внутренними гранями

Файл:строка: `src/Cad2Gdml.Core/Meshes/ComponentSplitter.cs:20-26` (если не все компоненты замкнуты, результат по рёбрам отбрасывается и берётся группировка по вершинам), `:109` (`IsAllClosed`). Ребро общей грани у двух тел имеет 4 грани, в склейку по рёбрам не входит, треугольники общей грани остаются одиночными, «замкнутость» нарушена, запасной путь склеивает всё по общим вершинам.

Воспроизведение (пробник `Probe.exe t_face_same.stl water_sample.stl`; `t_face_same` = два бокса 20x20x40 друг на друге, 24 треугольника):

```
t_face_same: rc=0 parts=2 t_face_same[Other,24,G4_AIR] water_sample[Source,256,G4_WATER]
diag: W_MESH_NONMANIFOLD,I_ROLE,I_ROLE,W_NO_CRYSTAL,W_MAT_DEFAULT      (нет I_SPLIT)
```

Стопки из 3, 4, 5 боксов, из 4 боксов с разными нижними гранями, `t_dup` (два совпавших тела) ведут себя так же: 36, 48, 60 треугольников в одной детали, `W_NO_CRYSTAL`/роль/материал одни на все тела. GDML содержит один `tessellated` на 24 грани с внутренней перегородкой (в отчёте: «тетра», объём 32 см³, габарит 20x20x80). Потери треугольников нет (это снимает B1 из v0.5), но реалистичный случай «кристалл поставлен на корпус того же сечения в одном файле» не разделяется: роль, вещество и объём назначаются на всю связку, предупреждение не говорит, что делать (раздельные файлы).

Побочный дефект: при `--no-split` сообщение `E_MESH_NONMANIFOLD` советует «Уберите --no-split: касающиеся тела разделятся» (`Cad2GdmlPipeline.cs:271`). Для этого входа неверно:

```
cad2gdml t_face_same.stl water_sample.stl ... --no-split   -> код 3 E_MESH_NONMANIFOLD ... Уберите --no-split: касающиеся тела разделятся.
cad2gdml t_face_same.stl water_sample.stl ...              -> код 0, Тесселированных: 1 (не разделилось)
```

Тест `face_touch_kept` проверяет только «сумма 24 и нет E_MESH_OPEN» и проходит и при разделении, и при склейке. Считаю ли склейку задуманной (`face_touch_kept` называет её «kept»), решает владелец; отмечено как расхождение с советом в сообщении и как риск для Geant4.
