## Архитектура v2
1. **`tools/gdml2in/` (fork, Python, Ф0)** — автоматизация того, что Amber сделал руками: разведка GDML (импорт функций
   `gdml_summary.py` через `sys.path`, не копия), толщины обвязки лучами (`shell_dims.py`), слияние слоёв по таблице H:279-285 в поля
   DS_*, проба (polycone/Маринелли) в SM_*, вещества — по соответствию `G4_*`/своих имён GDML → имена `GeometryMaterialSeed.Rows`
   (таблица ~15 строк, без новых плотностей: плотность берётся из GDML `<D>`), запись `.in` через setkey/setmat в корпусной шаблон;
   отчёт `*.gdml2in.json`: что отброшено (объём, материал, масса, доля массы). Роль объёма: `<auxiliary auxtype="BecqMoni:Role">`
   если есть (Geant4 принимает любой auxtype — `G4GDMLRead.cc:328-339`), иначе правило по имени (`crystal|NaI|LaBr`, `Source|Matrix`,
   `Vessel|Wall`), иначе — явный аргумент `--crystal <LV> --source <LV>`; молча не угадывать.
2. **`tools/g4csv2lsrm/`** — CSV Geant4 → TXT ЛСРМ (`Energy, keV<TAB>Efficiency<TAB>Uncertainty, %`; узлы eps=0 отброшены) для
   существующего импорта кривой конструктором (`EfficiencyMakerForm.cs:87-99, 547-580`); в шапку файла — определение ε (`fep_net`).
3. **`tools/cad2gdml/` (fork, Ф0b, после Ф0)** — CAD → GDML: STEP/IGES → OCP (Apache-2.0; OCCT LGPL-2.1+искл.) с распознаванием тел
   вращения; STL/OBJ/3MF/PLY → trimesh (MIT); glTF — метры → мм; STL — единицы по флагу `--unit`; FBX → `blender -b`. Формат выходов
   совместим с `GEANT4\scripts\build_gs2020_gdml.py` (`_manifest.json`, `materials.json`, `profile.json`). Проверки: замкнутость,
   нормали (объём > 0), вырожденные < 1e-9 мм², объём к B-rep ±0,1 % (только STEP/IGES), пересечения — `GEANT4\cadmesh-check`
   (просьба контуру), масса ±2 % при паспортной. #FC-1 до установки OCP/trimesh (trimesh уже стоит у GEANT4 — проверить реестр).
4. **BecqMoni-апстрим** — только по согласию Amber: (Ф1′) `tools/gdml2in` как Python-утилита рядом с `tools/CORPUS` (его же стиль
   AMBER234) ИЛИ (Ф1) чтение `*.gdml` в диалоге конструктора (C#, `EfficiencyMakerForm.cs:554-558, :564`) — выбирает он.
   (Ф2) кнопка на вкладке — только вопрос. (Ф3) список колец/брусьев — только после Ф1 и его «да». (Ф4) скетч — вместе с Ф3.
5. **Контур GEANT4** — не правим; письмо: (а) пометка ролей `BecqMoni:Role` в `build_*_gdml.py`; (б) прогон «шаблонной» сцены
   (цилиндры по полям `.in`) как GDML для оценки цены упрощения; (в) `cadmesh-check` для пересечений.
