Write ONE Python 3.12 script `step_export.py` using ONLY the stdlib and the OpenCASCADE bindings package `OCP` (python wheel `cadquery-ocp-novtk` 8.0.1.1; import names are like `from OCP.STEPCAFControl import STEPCAFControl_Reader`; static methods carry the suffix `_s`, e.g. `XCAFApp_Application.GetApplication_s()`, `XCAFDoc_DocumentTool.ShapeTool_s(label)`, `XCAFDoc_ShapeTool.IsAssembly_s(label)`, `GetComponents_s`, `GetReferredShape_s`, `GetLocation_s`, `GetShape_s`, `TDataStd_Name.GetID_s()`). Start with `sys.stdout.reconfigure(encoding="utf-8")`.
Usage: `python step_export.py <input.step> <outdir> [--deflection 0.05]` (deflection in mm, default 0.05, angular deflection 0.3 rad).
Behaviour: 1. Create the output directory. 2. Set `Interface_Static.SetCVal_s("xstep.cascade.unit", "MM")` and `Interface_Static.SetIVal_s("read.stepcaf.subshapes.name", 1)` (from OCP.Interface). 3. Create an XCAF document: `app = XCAFApp_Application.GetApplication_s(); doc = TDocStd_Document(TCollection_ExtendedString("MDTV-XCAF")); app.InitDocument(doc)`; read the file with `STEPCAFControl_Reader` (`SetNameMode(True)`, `SetColorMode(True)`, `ReadFile(path)` must return `IFSelect_RetDone` else print a JSON error line `{"error":"E_STEP_READ","message":...}` and exit 2; `Transfer(doc)` must return True else the same error and exit 2). 4. `shape_tool = XCAFDoc_DocumentTool.ShapeTool_s(doc.Main())`; `free = TDF_LabelSequence(); shape_tool.GetFreeShapes(free)`. 5. Walk the product tree recursively (depth limit 50): for a label that `IsAssembly_s`, get its components (`TDF_LabelSequence`, `GetComponents_s(label, comps)`), for each component label take its referred label (`GetReferredShape_s(comp, ref)` into a `TDF_Label`), accumulate the placement: the location of a component is `XCAFDoc_ShapeTool.GetLocation_s(comp)` (a `TopLoc_Location`), the accumulated one is `parent_loc * comp_loc` (the `*` operator on TopLoc_Location); the part name is the name of the referred label (fallback: the component label, then `part_<index>`). For a label that is NOT an assembly (a leaf part) take `shape = XCAFDoc_ShapeTool.GetShape_s(label)`, move it with the accumulated location (`shape.Moved(loc)`), and emit one part with the leaf name. Names: read via `name_attr = TDataStd_Name(); if label.FindAttribute(TDataStd_Name.GetID_s(), name_attr): name_attr.Get().ToExtString()`; strip, replace characters invalid in file names (`\\/:*?"<>|`) with `_`, empty -> `part_<index>`; duplicate names get suffix `_2`, `_3`.
6. For every emitted part: `BRepMesh_IncrementalMesh(shape, deflection, False, 0.3, True)`; write a BINARY STL with `StlAPI_Writer` (`writer.ASCIIMode = False`, `writer.Write(shape, path)`) to `<outdir>/<NNN>_<name>.stl` (NNN = 3-digit running index); count its triangles from the STL file size ((size-84)//50). Skip a part when the written file has 0 triangles.
7. Write `<outdir>/_manifest.json` (UTF-8, ensure_ascii False, indent 1) = {"source": <input path>, "unit": "mm", "parts": [{"name": ..., "file": <file name only>, "triangles": N}, ...]} and print one final line of JSON `{"ok":true,"parts":<count>,"triangles":<sum>}`; exit 0. When there are no parts print `{"error":"E_STEP_EMPTY","message":"no solids"}` and exit 3. Any other exception: print `{"error":"E_STEP_INTERNAL","message":<repr>}` and exit 4. No network access, no subprocess, no file access outside the input file and the output directory. Keep it under 120 lines; think briefly.
