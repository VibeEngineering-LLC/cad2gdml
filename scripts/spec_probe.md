Write ONE Python 3 script `stl_probe.py` (stdlib only). Usage: `python stl_probe.py <file.stl>`. Start with `sys.stdout.reconfigure(encoding="utf-8")`. Read a BINARY STL (80-byte header, uint32 count, then 50 bytes per triangle: 12 floats normal+3 vertices, uint16). For each weld tolerance in (1e-5, 1e-3, 1e-2) mm: weld vertices by key = tuple(round(c / tol) for c in vertex); build triangles as index triples; skip triangles with repeated indices; build an edge map (min,max index pair -> list of triangle ids); union-find over triangle ids joining the two triangles of every edge used by exactly 2 triangles. Print one line: tol, component count, the sizes of the 10 largest components, count of components with fewer than 4 triangles and their total triangle count, number of edges used once (open edges) in the whole mesh and number of edges used 3 or more times. Then, for tol 1e-3 only, print for the 8 largest components: triangle count, number of open edges inside it, and its bounding box (min and max for x, y, z, rounded to 0.01). Keep it under 70 lines; think briefly.
