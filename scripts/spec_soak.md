Write ONE Python 3 script `soak.py` (stdlib only, no third-party packages). Usage: `python soak.py <cad2gdml.exe> <workdir> <input> [<input>...] [--runs N] [--flags "..."]` (defaults: runs 20, flags "--unit mm --allow-default-material --drop-open").
Behaviour: for run index 1..N call `<exe> <inputs> --out <workdir>/run_<k> <flags split with shlex>` with subprocess.run (capture output, timeout 300 s, UTF-8 decode with errors="replace"), measure wall time with time.perf_counter. After each run compute SHA-256 of every `*.gdml` file in that out folder (hashlib, read in 1 MiB blocks). Print one line per run: index, exit code, seconds, first 12 hex chars of each gdml sha. At the end print a summary: the set of distinct exit codes, the set of distinct sha tuples (stability means exactly one), min / median / max seconds (statistics module), and the ratio of the mean of the last 5 run times to the mean of the first 5 (a drift indicator; print "n/a" when N < 10). Exit code of the script: 0 when exit codes are identical across runs and sha tuples are identical, 1 otherwise, 2 for bad arguments. Delete each run folder after hashing unless `--keep` is given. Start with `sys.stdout.reconfigure(encoding="utf-8")`. Keep it under 90 lines; think briefly.
